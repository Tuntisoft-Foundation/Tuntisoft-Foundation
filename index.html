About Us

Tuntisoft Foundation is an independent software foundation focused on creating original languages and tools for the next generation.

Our mission is to make software development accessible, understandable, and enjoyable for everyone—especially beginners.

Our Projects

A family of original languages and tools developed by Tuntisoft Foundation.

Tayo

General-purpose programming language.

Tiny

Structured query language for simple data management.

TinyML

Markup & visualization language.

Tayo Shell

Command-line environment for the ecosystem.

Ecosystem

A complete foundation covering programming, database, markup, shell, and API layers.

Tayo + Tiny + TinyML + Tayo Shell work together as one unified platform, enabling learning, automation, and visualization.
